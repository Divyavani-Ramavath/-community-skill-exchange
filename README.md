# Community-Skill-Exchange

## Empowering People to Learn, Share and Connect

Community-Skill-Exchange is a browser-based community learning platform that helps users discover skills, connect with people, exchange knowledge, set learning goals, track activities and monitor their progress.

The project is designed as a frontend-only application using HTML, CSS, JavaScript and LocalStorage.
